# FarmPrism — Sell Page Asset & Developer Handoff

## Technology
- React Native
- Expo
- Android-first
- Design reference: 1080 × 2340 px (9:19.5)

## Purpose
The Sell page is the farmer's direct path from available produce to a transparent sale.

Core journey:

`SELECT PRODUCE → QUANTITY → QUALITY → MARKET PRICE → PRICE PREDICTION → BUYER OFFERS → COMPARE → ACCEPT → ORDER`

## Asset rule
The reference screenshot is for measurement only. Individual artwork is supplied separately. Dynamic UI text, prices, quantities, dates, buyer counts, buttons and navigation must be rendered in React Native.
