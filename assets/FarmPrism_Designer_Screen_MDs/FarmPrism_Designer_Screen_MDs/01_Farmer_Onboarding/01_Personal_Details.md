# Farmer Personal Details

**Purpose:** Collect identity details on first setup

## Show
- Profile photo
- Full name
- Mobile number
- 11-digit Farmer ID

## Click / Navigation
- Add Photo → Camera/Gallery preview
- Continue → Farm Details
- Sign out

## Flow
- Role Selection → Personal → Farm Details

## Important
- Farmer ID is a government identifier, not DB PK.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
