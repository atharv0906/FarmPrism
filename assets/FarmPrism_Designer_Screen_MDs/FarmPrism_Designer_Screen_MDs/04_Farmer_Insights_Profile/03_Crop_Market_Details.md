# Crop Market Details

**Purpose:** Summarized market detail for one crop

## Show
- Current
- Min
- Max
- Trend summary
- Next 7-day outlook
- Source/date

## Click / Navigation
- Sell This Crop → Sell flow if available
- Back → Insights

## Flow
- Home crop tile/Insights → Crop Detail

## Important
- Backend/AI analyzes history internally; farmer sees summary only.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
