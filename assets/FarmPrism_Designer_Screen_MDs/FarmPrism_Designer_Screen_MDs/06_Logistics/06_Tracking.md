# Delivery Tracking

**Purpose:** Send location updates

## Show
- Current tracking state
- Actual GPS action
- Collapsed DEVELOPMENT ONLY simulation
- Latest update

## Click / Navigation
- Actual Location → send GPS
- Simulated Location → dev-only write
- Back → Active

## Flow
- Active Delivery → Tracking

## Important
- Do not expose unnecessary precise coordinates.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
