# Logistics Home

**Purpose:** Delivery partner dashboard

## Show
- Profile summary
- Verified
- Trust Score
- Vehicle/capacity
- Available Jobs
- Active Jobs
- Completed deliveries
- Bottom nav: Home / Jobs / Active / History / Profile

## Click / Navigation
- Find Jobs
- Active Delivery
- History
- Profile
- Notifications

## Flow
- Login as Logistics → Home

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
