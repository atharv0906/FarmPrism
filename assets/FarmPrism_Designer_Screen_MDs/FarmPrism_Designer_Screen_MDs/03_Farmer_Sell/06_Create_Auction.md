# Create Auction

**Purpose:** Publish a timed auction

## Show
- Crop/batch summary
- Quantity
- Reserve price
- Duration: 6h / 12h / 24h
- 24h default
- Grade
- Publish Auction

## Click / Navigation
- Publish → Auction Details
- Back → Choose Method

## Flow
- Choose Method → Create Auction → Auction Details

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
