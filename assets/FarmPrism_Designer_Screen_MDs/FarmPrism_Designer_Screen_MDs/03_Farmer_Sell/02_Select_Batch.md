# Select Batch

**Purpose:** Choose an available physical batch to sell

## Show
- Crop artwork
- Batch code
- Available quantity
- Current Farmer Declared Grade
- Status

## Click / Navigation
- Select Batch → Farmer Declared Quality
- Back → Sell Home

## Flow
- Sell Home → Select Batch

## Important
- Only sellable batches.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
