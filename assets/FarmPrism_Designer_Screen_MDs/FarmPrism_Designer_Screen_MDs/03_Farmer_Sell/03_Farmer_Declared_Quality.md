# Farmer Declared Quality

**Purpose:** Farmer chooses Grade A/B/C

## Show
- Crop + batch
- Current grade
- A/B/C chips/cards
- Optional notes
- Continue

## Click / Navigation
- Select A/B/C
- Continue → save quality → Price Insight
- Conflict → friendly message + refresh

## Flow
- Select Batch → Quality → Price Insight

## Important
- Never say AI Verified or Certified.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
