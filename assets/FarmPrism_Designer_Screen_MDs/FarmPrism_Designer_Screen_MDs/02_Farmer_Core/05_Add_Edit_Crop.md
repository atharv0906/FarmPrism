# Add / Edit Crop

**Purpose:** Add or edit crop information

## Show
- Crop selector: Tomato/Onion/Potato
- Status
- Available quantity/batch fields as supported

## Click / Navigation
- Save → Crop Details/My Crops
- Cancel → previous
- Unsaved changes → discard confirmation

## Flow
- My Crops → Add Crop
- Crop Details → Edit Crop

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
