# Farmer Home

**Purpose:** Daily summary: “What matters today.”

## Show
- Header + Notifications
- Farm summary
- Active Auctions
- New Offer
- Sold This Month
- Top Opportunity
- Quick Actions
- Bottom nav: Home / My Farm / Sell / Insights / Profile

## Click / Navigation
- Bell → Notifications
- Manage My Farm → My Farm
- View Offers → Buyer Offers
- View Market → Insights
- List Produce → Sell
- My Orders → Orders
- Crop tile → Crop Market Details

## Flow
- Main Farmer landing screen

## Important
- Frozen approved design. No Trust Score on Home.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
