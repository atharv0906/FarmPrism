# Buyer Home

**Purpose:** Buyer marketplace dashboard

## Show
- Business/profile summary
- Verified badge
- Trust Score
- Open Auctions
- Fixed Listings
- Active Bids/Requests
- Orders
- Bottom nav: Home / Market / My Bids / Orders / Profile

## Click / Navigation
- Explore Market
- My Bids
- Orders
- Profile
- Notifications

## Flow
- Login as Buyer → Buyer Home

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
