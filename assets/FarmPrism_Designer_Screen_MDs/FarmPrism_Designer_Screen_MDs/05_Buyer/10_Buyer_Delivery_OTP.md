# Buyer Delivery OTP

**Purpose:** Show Buyer delivery code

## Show
- 6-digit OTP
- Expiry
- Instruction to tell Logistics
- Regenerate when expired/attempts exhausted

## Click / Navigation
- Generate/Regenerate
- Back → Order

## Flow
- Buyer Order → Delivery OTP

## Important
- OTP verification itself confirms delivery.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
