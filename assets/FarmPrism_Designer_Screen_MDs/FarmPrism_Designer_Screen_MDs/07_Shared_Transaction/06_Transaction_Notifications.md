# Shared Notification Pattern

**Purpose:** Common notification design language

## Show
- Icon
- Title
- Short body
- Clean time
- Unread state

## Click / Navigation
- Tap → canonical destination
- Mark read

## Flow
- Bell/event deep-link → Notifications

## Important
- Never show raw entity IDs or backend codes.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
