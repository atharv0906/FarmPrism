# Simulated Payment Action

**Purpose:** Prototype payment confirmation

## Show
- Payment type
- Payee
- Amount
- Simulation label
- Confirm

## Click / Navigation
- Confirm → simulated payment success → Order refresh
- Cancel → Order

## Flow
- Order Details → Payment Action

## Important
- Farmer advance, 40% Logistics advance, final balances. Not a real gateway.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
