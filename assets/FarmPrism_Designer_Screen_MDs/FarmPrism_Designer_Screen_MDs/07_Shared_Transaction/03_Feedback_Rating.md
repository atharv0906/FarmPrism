# Feedback / Rating

**Purpose:** Collect post-completion feedback

## Show
- Counterparty
- 1–5 rating
- Optional comment
- Submit

## Click / Navigation
- Submit → success → Order/Profile
- Back → Order

## Flow
- Completed Order → Feedback

## Important
- One feedback per relationship/transaction.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
