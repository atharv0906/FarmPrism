# Shared Order Details

**Purpose:** Reusable order/timeline layout by role

## Show
- Order code
- Crop
- Quantity
- Unit price
- Total
- Advance terms
- Farmer
- Buyer
- Logistics when assigned
- Timeline/status

## Click / Navigation
- Show only role-valid action
- Profiles → Public Profile
- Tracking → Tracking

## Flow
- Orders/History/Notifications → Order Details

## Important
- Do not create three unrelated order-detail designs.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
