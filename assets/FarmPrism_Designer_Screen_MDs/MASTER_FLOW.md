# FarmPrism — Master Screen Flow

## Common
Splash → Language → Get Started → Login/OTP → Role Selection (only when needed) → Role app

## Farmer
Home ↔ My Farm ↔ Sell ↔ Insights ↔ Profile

Sell Produce → Select Batch → Farmer Declared Quality → Price Insight → Choose Selling Method

Auction: Choose Method → Create Auction → Auction Details → Buyer Offers → Offer Details → Accept → Order

Fixed Price: Choose Method → Create Fixed Price → Listing Details → Purchase Requests → Request Details → Accept → Order

Order: Buyer advance → Logistics job → Fee → 40% Logistics advance → Pickup → Tracking → Delivery OTP → Final balances → Completed → Feedback → Trust update

## Buyer
Home ↔ Market ↔ My Bids ↔ Orders ↔ Profile

Auction: Market → Auction Details → Place/Revise Bid → My Bids → Accepted → Order

Fixed: Market → Fixed Details → Request Purchase → My Bids → Accepted → Order

## Logistics
Home ↔ Jobs ↔ Active ↔ History ↔ Profile

Jobs → Job Details → Claim → Propose Fee → Buyer accepts + pays 40% → Pickup → Tracking → Delivery OTP → Completed
