# Active Delivery

**Purpose:** Show assigned job and stage

## Show
- Order/job summary
- Stage timeline
- Pickup/delivery
- Fee/payment state
- Tracking state

## Click / Navigation
- Confirm Pickup
- Open Tracking
- Enter OTP
- View Farmer/Buyer

## Flow
- Bottom nav Active → Active Delivery

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
