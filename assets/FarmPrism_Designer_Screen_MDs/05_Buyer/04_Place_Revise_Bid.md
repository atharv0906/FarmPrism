# Place / Revise Bid

**Purpose:** Create or revise auction bid

## Show
- Quantity
- Buyer price per KG
- Advance % 10–90
- Saved delivery location
- Optional edit delivery

## Click / Navigation
- Submit → My Bids
- Use saved location
- Back → Listing

## Flow
- Auction Details → Bid Form → My Bids

## Important
- Old bid remains history; one active current bid per Buyer/Auction.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
