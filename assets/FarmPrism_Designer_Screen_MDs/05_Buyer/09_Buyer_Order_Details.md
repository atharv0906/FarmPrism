# Buyer Order Details

**Purpose:** Buyer transaction control center

## Show
- Order summary
- Farmer
- Payment states
- Logistics
- Tracking summary
- Timeline
- Current valid action

## Click / Navigation
- Pay Farmer Advance
- Accept/Reject Logistics Fee
- Pay 40% Logistics Advance
- View/Generate OTP
- Pay Final Balances
- View Tracking
- Submit Feedback

## Flow
- Buyer Orders → Order Details

## Important
- Payments are clearly labelled simulated.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
