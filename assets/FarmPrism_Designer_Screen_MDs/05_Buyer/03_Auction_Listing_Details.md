# Buyer Auction Details

**Purpose:** Inspect an auction before bidding

## Show
- Crop/batch
- Remaining quantity
- Grade
- Reserve price
- Farmer profile/trust
- End time
- Market reference if available

## Click / Navigation
- Place Bid
- Revise Bid if active
- Withdraw Bid
- View Farmer

## Flow
- Buyer Market → Auction Details

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
