# Farmer Profile

**Purpose:** Authenticated Farmer profile and trust

## Show
- Name
- Verification
- Farmer ID
- Farm/location
- Farm area
- Trust Score
- Completed transactions
- Reliability/quality summary

## Click / Navigation
- Edit Profile/Farm
- Logout → Login

## Flow
- Bottom nav Profile → Farmer Profile

## Important
- Trust Score is not on Farmer Home.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
