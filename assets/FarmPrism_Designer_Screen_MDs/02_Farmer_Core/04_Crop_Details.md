# Crop Details

**Purpose:** Single-crop inventory and selling context

## Show
- Crop image/name
- Status
- Available quantity
- Batch count
- Relevant activity

## Click / Navigation
- Market Price → Crop Market Details
- Sell Produce → Sell flow
- Buyer Interest → Buyer Offers
- Previous Sales → Selling History

## Flow
- My Crops/My Farm → Crop Details

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
