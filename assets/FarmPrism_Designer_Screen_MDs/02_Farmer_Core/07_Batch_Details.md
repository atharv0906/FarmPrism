# Physical Batch Details

**Purpose:** View a single physical batch

## Show
- Batch code
- Crop
- Remaining quantity
- Status
- Farmer Declared Grade
- Current listing state

## Click / Navigation
- Sell → Sell flow if available
- View active listing if already listed
- Back → Available Produce

## Flow
- Available Produce → Batch Details

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
