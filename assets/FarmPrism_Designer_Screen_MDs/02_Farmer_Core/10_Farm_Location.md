# Farm Location / Map

**Purpose:** Show farm location safely

## Show
- Map/location summary
- Farm label
- Village/city/district/state

## Click / Navigation
- Edit location → Edit Farm
- Back → My Farm

## Flow
- My Farm → Farm Location

## Important
- Do not expose private precision unnecessarily.
