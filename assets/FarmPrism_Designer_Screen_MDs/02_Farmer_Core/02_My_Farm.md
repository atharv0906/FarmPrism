# My Farm

**Purpose:** Farm inventory root: “What I have.”

## Show
- Hero/header
- Farm Overview: Total Land / Crops / Available to Sell / Active Batches
- My Crops cards
- Farm location
- Bottom nav

## Click / Navigation
- Edit Farm → Edit Farm
- Crops/View All → My Crops
- Available to Sell → Available Produce
- Crop Details → Crop Details
- Add New Crop → Add Crop
- Farm location → Map

## Flow
- Farmer Home / bottom nav → My Farm

## Important
- Frozen. No soil health, irrigation, harvest dates or farm photos.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
