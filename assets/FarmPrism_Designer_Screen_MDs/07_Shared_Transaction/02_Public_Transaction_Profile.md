# Public Transaction Profile

**Purpose:** Safe counterparty profile

## Show
- Name/business
- Role
- Verified
- Trust Score
- Completed transactions
- Role reliability metric

## Click / Navigation
- Back → previous transaction screen

## Flow
- Buyer↔Farmer; Farmer/Buyer↔Logistics; Logistics↔Farmer/Buyer

## Important
- Never expose exact private GPS.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
