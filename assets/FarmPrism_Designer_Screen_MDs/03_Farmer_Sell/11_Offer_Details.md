# Offer Details

**Purpose:** Inspect and accept/reject one Buyer bid

## Show
- Buyer public profile
- Trust Score
- Price
- Requested quantity
- Advance %
- Delivery summary
- Accepted quantity

## Click / Navigation
- Accept full/partial → Order
- Reject → confirmation
- View Buyer Profile

## Flow
- Buyer Offers → Offer Details → Order

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
