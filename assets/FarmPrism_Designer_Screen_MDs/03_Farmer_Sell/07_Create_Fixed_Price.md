# Create Fixed Price

**Purpose:** Publish a fixed-price listing

## Show
- Crop/batch summary
- Quantity
- Fixed price
- 24-hour expiry info
- Grade
- Publish Fixed Price

## Click / Navigation
- Publish → Fixed Listing Details
- Back → Choose Method

## Flow
- Choose Method → Create Fixed Price → Listing Details

## Important
- Active until sold, closed, or 24h expiry.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
