# Fixed Price Listing Details

**Purpose:** Manage a fixed-price listing

## Show
- Crop/batch
- Remaining quantity
- Fixed price
- Grade
- Expiry
- Status
- Request count

## Click / Navigation
- View Purchase Requests
- Close Listing
- Back → Sell Home

## Flow
- Publish/Sell Home → Fixed Listing Details

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
