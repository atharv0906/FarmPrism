# Auction Details

**Purpose:** Manage a published auction

## Show
- Crop/batch
- Offered + remaining quantity
- Reserve price
- Grade
- Time remaining/end time
- Status
- Buyer bid count

## Click / Navigation
- View Buyer Offers
- Close Auction Early
- Back → Sell Home

## Flow
- Publish/Sell Home → Auction Details

## Important
- No automatic highest-bid award; Farmer decides.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
