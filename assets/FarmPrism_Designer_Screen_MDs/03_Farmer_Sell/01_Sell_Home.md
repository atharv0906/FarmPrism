# Sell Home

**Purpose:** Selling dashboard for active listings and selling actions

## Show
- Overview: Active Auctions / Fixed Listings / Buyer Offers / Purchase Requests
- Sell Produce
- Buyer Offers
- Purchase Requests
- Selling History
- My Orders
- Active Listings

## Click / Navigation
- Sell Produce → Select Batch
- Buyer Offers → Offers
- Purchase Requests → Requests
- Selling History → History
- My Orders → Orders
- Listing → Details

## Flow
- Bottom nav Sell → Sell Home

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
