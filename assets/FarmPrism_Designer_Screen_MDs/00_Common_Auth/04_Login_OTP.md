# Login + OTP

**Purpose:** Phone login and OTP verification on one screen

## Show
- Phone input with +91
- Send OTP
- 6-digit OTP inputs
- Resend OTP
- Login
- Trust/security note

## Click / Navigation
- Send OTP → OTP entry
- Any 6-digit OTP works in prototype
- Login → fixed demo account + permanent role

## Flow
- Get Started → Login → role flow

## Important
- No API/debug text in UI.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
