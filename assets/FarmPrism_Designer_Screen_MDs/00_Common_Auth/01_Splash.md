# Splash Screen

**Purpose:** Brand entry while app/session state is restored

## Show
- FarmPrism logo
- Clean branded background
- Short loading/brand moment

## Click / Navigation
- No main CTA
- Auto-continue after session/language/role check

## Flow
- First launch → Language Selection
- Returning valid user → remembered role dashboard
- Expired/no session → Login

## Important
- No role switcher here.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
