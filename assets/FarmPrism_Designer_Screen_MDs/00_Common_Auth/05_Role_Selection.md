# Role Selection

**Purpose:** Choose/confirm permanent app role

## Show
- Farmer
- Buyer
- Logistics
- FPO Dashboard — Coming Soon

## Click / Navigation
- Assigned role → select
- Continue → role setup/dashboard
- FPO → Coming Soon
- Unassigned role → unavailable

## Flow
- Login → Role Selection → role app

## Important
- One login = one permanent role; no role switcher.

## Visual Direction
- Android-first; use approved FarmPrism Farmer Home/My Farm as the visual master.
- Cream/green/earthy palette, rounded white cards, soft shadows, clean icons, large touch targets.
- Use existing FarmPrism logo/artwork language; avoid generic admin-dashboard styling.
